SKINCARE

Moments of Calm for Your Skin

01

PEELING

DESCRIPTION

古い角質を取り除き、なめらかで透明感のある肌へ導くピーリング。

HOW TO USE

洗顔後、水気を軽く拭き取り、適量を顔全体になじませた後、水またはぬるま湯で洗い流してください。

BENEFITS

  • 古い角質をやさしく除去
  • 透明感のある肌へ
  • キメを整える
  • スキンケアの浸透をサポート
02

TONER

DESCRIPTION

洗顔後の肌をやさしく整え、みずみずしい潤いを与えるトナー。

HOW TO USE

コットンまたは手に適量を取り、顔全体になじませてください。

BENEFITS

  • 肌を整える
  • うるおい補給
  • 乾燥を防ぐ
  • なめらかな肌へ導く
03

LOTION

DESCRIPTION

豊かな潤いで肌を満たし、しっとりとしたやわらかな肌へ導くローション。

HOW TO USE

トナーの後、適量を手に取り顔全体へなじませてください。

BENEFITS

  • 長時間保湿
  • 肌をやわらかく保つ
  • 乾燥による肌荒れを防ぐ
  • うるおいをキープ
04

SERUM

DESCRIPTION

厳選された美容成分を配合した美容液。肌にハリとツヤを与えます。

HOW TO USE

ローションの後、適量を顔全体になじませてください。

BENEFITS

  • ハリ感アップ
  • ツヤを与える
  • 集中保湿
  • 肌コンディションを整える
