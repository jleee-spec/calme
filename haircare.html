HAIRCARE

Beauty Begins With Healthy Hair

01

SHAMPOO

DESCRIPTION

やさしく洗い上げながら、頭皮と髪を健やかに整えるシャンプー。

HOW TO USE

髪を十分に濡らし、適量を泡立てて洗浄後、しっかり洗い流してください。

BENEFITS

  • 頭皮をやさしく洗浄
  • きめ細かな泡立ち
  • うるおいを保つ
  • 軽やかな仕上がり
02

TREATMENT

DESCRIPTION

髪にうるおいを与え、なめらかな指通りへ導くトリートメント。

HOW TO USE

シャンプー後、水気を軽く切り、毛先になじませて洗い流してください。

BENEFITS

  • ダメージ補修
  • まとまり感アップ
  • 指通りを改善
  • ツヤを与える
03

HAIR MILK

DESCRIPTION

髪をやわらかく整え、自然なまとまりを与える洗い流さないヘアミルク。

HOW TO USE

タオルドライ後、適量を毛先中心になじませてください。

BENEFITS

  • うるおい補給
  • パサつきを抑える
  • 軽やかな質感
  • 自然なまとまり
04

HAIR OIL

DESCRIPTION

髪に上品なツヤを与え、指通りなめらかな仕上がりへ。

HOW TO USE

少量を手に取り、毛先中心になじませてください。

BENEFITS

  • 艶感アップ
  • 広がりを抑える
  • 熱ダメージケア
  • シルキーな質感
