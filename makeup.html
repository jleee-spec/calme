Color Your Calm

01

LIPSTICK

DESCRIPTION

なめらかな塗り心地で、唇を美しく彩るリップスティック。

HOW TO USE

唇の中央から外側へ向かってやさしく塗布してください。

BENEFITS

  • 鮮やかな発色
  • 長時間キープ
  • うるおいを保つ
  • なめらかな仕上がり
02

GLOSS

DESCRIPTION

透明感のあるツヤで、唇に上品な輝きを与えるグロス。

HOW TO USE

唇全体に均一になじませてください。
リップの上から重ねても使用できます。

BENEFITS

  • 自然なツヤ感
  • 軽やかなつけ心地
  • うるおいをキープ
  • 立体感のある唇へ
